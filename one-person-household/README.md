# ROAD ON · 1인 가구 수업 앱

초등학교 3학년 사회 수업용 로컬 시제품입니다.

## 접속 코드

- 선생님: `2026`
- 탐사 1: `1인분` (`한 그릇`, `소량 주문`도 인식)
- 탐사 2: `가전제품` (`한 뼘`, `작은 가전`, `소형 가전`도 인식)
- 탐사 3: `쌓인 우유` (`우유 배달`, `안부`도 인식)

## 수업 흐름

1. 2000~2020년 1인 가구 비율 변화 확인
2. 결혼에 대한 생각, 학업·직장, 배우자와의 사별 자료 추론
3. 식생활·생활용품·돌봄 기사 탐구
4. 발견 기록과 탐정 보고서 작성

GitHub Pages에서 별도 주제 앱으로 제공합니다.
