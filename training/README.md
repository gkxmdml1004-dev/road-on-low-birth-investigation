# ROAD ON 교사 연수용 기사문 활동 모음

학생용 사회 변화 탐구 앱에 포함된 기사문 활동 15개를 교사 연수에서 빠르게 체험할 수 있도록 모은 별도 웹앱입니다.

## 실행 주소

저장소 루트에서 로컬 서버를 실행한 뒤 `/training/`으로 접속합니다.

예: `http://127.0.0.1:8771/training/`

## 구성

- 저출산 3개
- 고령화 3개
- 1인 가구 3개
- 반려동물 문화 3개
- 외국인 이주민 문화 3개

각 기사 화면에서 학생처럼 증거 낱말을 수집하고 낱말 풀이를 확인할 수 있습니다. 교사 해설에는 학생 행동, 발문 예시, 관찰 포인트를 제시했습니다.

## 원본 수업 자료가 바뀐 경우

저장소 루트에서 아래 명령을 실행하면 `data.js`가 최신 기사 자료로 다시 만들어집니다.

```bash
node training/build-data.mjs
```
